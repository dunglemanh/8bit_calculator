8-bit Calculator (Verilog)

Overview
A simple 8-bit calculator implemented in Verilog HDL.

Features
- Basic ALU operations
- Register file
- Control unit
- Testbench included.

Directory Structure
- `src/rtl`: RTL modules
- `src/tb`: Testbench
- `sim`: Simulation scripts
- `docs`: Block diagrams and documentation.

Simulation
```bash
cd sim
./run_simulation.sh
